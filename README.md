# Дневник здоровья с анализом взаимосвязей

Веб-приложение для ведения дневника здоровья: сон, вес, калории, вода,
физическая активность, самочувствие и полезные привычки. Приложение
показывает статистику и графики, помогая увидеть взаимосвязи между
показателями (например, как сон влияет на самочувствие).

Проект выполняется в рамках дисциплины «Проектная деятельность», ТПУ.

## Функциональность MVP

- регистрация и вход пользователя;
- ввод данных за день;
- статистика и графики за выбранный период.

Планируется после MVP: советы на основе анализа данных с помощью ИИ.

## Стек

## Как запустить

```bash
git clone https://github.com/<user>/health-diary.git
cd health-diary
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

После запуска приложение доступно по адресу http://127.0.0.1:8000/
